# 🏏 Cricbuzz LiveStats Dashboard

A Real-Time Cricket Analytics Dashboard developed using Python, Streamlit, MySQL, and Cricbuzz RapidAPI.

## Features

- 📡 Live Match Tracking
- 📊 Top Player Statistics
- 🗄 SQL-Based Cricket Analytics
- ✏️ CRUD Operations on Player Data
- 📈 Interactive Streamlit Dashboard
- 🔗 Cricbuzz RapidAPI Integration
- 🐬 MySQL Database Connectivity

## Tech Stack

- Python
- Streamlit
- MySQL
- Pandas
- RapidAPI (Cricbuzz API)
- SQL

## Modules

### Home
Dashboard overview and navigation.

### Live Matches
Displays real-time match data, scorecards, venue information, and match status.

### Top Player Stats
Analyzes player performance metrics and rankings.

### SQL Analytics
Performs cricket data analysis using SQL queries and visualizations.

### CRUD Operations
Create, Read, Update, and Delete player records directly from the dashboard.
